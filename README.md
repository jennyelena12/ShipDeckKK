# ShipDeckKK - Premier Ship Dealership Website

## Overview

ShipDeckKK is a responsive maritime dealership website that showcases premium ships, company information, services, and achievements. The project was developed using Vanilla HTML, CSS, and JavaScript to provide an interactive and user-friendly browsing experience.

---

## Features

* Responsive navigation and layout
* Hero section with call-to-action
* Animated statistics counters
* Company profile and achievements showcase
* Service information section
* Ship gallery display
* Subscription form with client-side validation

---

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Font Awesome
